# Purpose

**Problem:** Orchestrating multiple AI agents with different perception states (asymmetric information) and collaborative decision-making lacks a generalizable framework for designing agent roles and decision flows.

**Audience:** AI researchers, game designers, and system architects exploring multi-agent coordination with incomplete information.

**Key constraints:** Must be design-first (patterns documented before code), support heterogeneous agent types, and provide verifiable semantics for information hiding and consensus.

**Success metric:** A designer can apply E.C.H.O. patterns to define a multi-agent scenario, and Claude (or other LLMs) can generate consistent behavior without manual per-agent tuning.
